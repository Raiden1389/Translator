# Plan: Native macOS Theme System
Created: 2026-02-09T23:11:27+07:00
Status: 🟡 In Progress

## Overview
Implement a comprehensive, dual-mode theme system based on Apple's macOS System Settings design language. Uses CSS Variables and semantic tokens to ensure a consistent, premium feel across the entire application.

## Tech Stack
- CSS Variables (Core & Semantic)
- Tailwind CSS (using theme variables)
- Framer Motion / CSS Transitions (for Motion tokens)
- ThemeProvider (Context API for mode switching)
