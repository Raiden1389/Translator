# 🚀 Raiden AI Translator v2.9.0 — Release Notes
> Released: 2026-03-06 | Build: `Raiden-AI-Translator-2.9.0.exe`

## Có gì mới?
- **Workflow-Embedded Engine**: Đưa luật dịch trực tiếp vào workflow `/dich` để AI không thể "quên" hay "bỏ qua" các quy tắc quan trọng (Ta/Ngươi, ẩn chủ ngữ).
- **Continuous Context**: Dịch batch nhiều chương như một task duy nhất, đảm bảo văn phong đồng nhất từ đầu đến cuối, không bị reset mỗi chương.
- **Fix JSON Truncation**: Khắc phục triệt để lỗi mất dữ liệu khi ghi file JSON cho các chương truyện cực dài.

## Cần bấm gì?
- Chỉ cần chạy lệnh `/dich` như bình thường. AI sẽ tự động áp dụng engine mới.
- Không cần migrate dữ liệu.
