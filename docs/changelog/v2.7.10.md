# 🚀 Raiden v2.7.10 — Release Notes

> **Released**: 2026-02-25 | **Build**: `Raiden-v2.7.10.exe`

---

## Có gì mới?

### 1. 🔥 Luyện Văn — Auto-Apply Pipeline
Thêm cải chính → **tự động áp dụng toàn bộ chương đã dịch**. Không cần bấm nút nào.

| Trước (v2.7.9) | Sau (v2.7.10) |
|-----------------|---------------|
| Thêm rule → chỉ lưu | Thêm rule → lưu + sweep toàn bộ |
| Dịch xong → text thô | Dịch xong → auto-apply corrections |
| Phải bấm "Apply" thủ công | Tự động, silent |

### 2. 🏗️ Architecture Refactor
- **1 engine** (`correction.ts`) — pure logic, production-grade
- **1 service** (`corrections.service.ts`) — DB operations  
- **3 thin hooks** — chỉ UI state, form, toast

### 3. 🎨 UI Polish
- Tab "Tuning" → "Luyện Văn" (dark mode fix)
- Button text rõ nghĩa hơn
