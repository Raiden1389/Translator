# 🚀 Raiden AI Translator v2.7.13 — Release Notes
> Released: 2026-03-04 | Build: `Raiden-v2.7.13.exe` (16.1 MB)

## Có gì mới?

### 🐛 Bug Fixes
- **Fix ReviewDialog save** — Sửa lỗi khi chỉnh sửa nhân vật/thuật ngữ trong dialog duyệt rồi bấm Lưu, các thay đổi bị mất (rename, xoá, blacklist đều ko lưu).
- **Fix build crash** — Sửa lỗi `Cannot access 'J' before initialization` khi build production (do import Tauri ở top-level).

### ✨ New Features
- **Nút xoá nhân vật** — Mỗi hàng trong tab Nhân vật giờ có icon 🗑️ hiện khi hover, bấm để xoá nhanh.
- **Nút "Dịch lại" bulk** — Chọn nhiều chương → thanh dock hiện nút 🔄 Dịch lại, xoá bản dịch cũ và dịch lại tất cả.
- **Post-cleanup engine** — Module mới tự động dọn output AI: xoá đoạn trùng lặp, chuẩn hoá dấu ngoặc kép, loại bỏ AI chatter tiếng Việt.
