# 🚀 Raiden v2.9.2 — Release Notes
> Released: 2026-03-07

## Có gì mới?

### 🔄 Bridge Auto-Import v2
App tự động poll outbox mỗi 2 giây, phát hiện file `done_*.json` sentinel từ Agent, và tự import chapters đã dịch — không cần bấm nút Import thủ công nữa. Dialog hiển thị real-time progress (e.g. "5/12 chapters (42%)") với state machine trực quan.

### 🛡️ Safe Cleanup
Files chỉ bị xóa sau khi xác nhận đã import đủ số chương mong đợi. Ngăn mất data khi import partial.

### 🔍 Self-QA Scan
Bước mới trong workflow `/dich`: Agent tự đọc lại toàn bộ outbox files, quét lỗi chính tả, typo, Hán Việt sống, glossary inconsistency — rồi sửa trực tiếp trước khi ghi done sentinel.

### 📝 /changelog Workflow
Workflow cập nhật changelog độc lập, có thể dùng cho bất kỳ project nào.

## Cần làm gì?
Không cần làm gì thêm. Cài bản mới và sử dụng bình thường.
